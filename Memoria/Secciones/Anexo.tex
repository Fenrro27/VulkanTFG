\section{Repositorio de Código Fuente}
\label{anexo:repositorio}

Todo el código fuente de este proyecto está publicado en GitHub para que esté disponible de forma libre \parencite{fenrro27_vulkan_tfg}. Esto incluye el motor gráfico en Vulkan, los \textit{shaders} de cómputo, la escena de prueba. El repositorio contiene los archivos del sistema, guías de compilación y el histórico de cambios que documenta la evolución de nuestras optimizaciones.
También está disponible el repositorio con las comparativas con OpenGL \parencite{fenrro27_vulkan_vs_opengl}.
