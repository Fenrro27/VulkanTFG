\chapter{Justificación y Objetivos}
\label{sec:justificacion_y_objetivos}

\section{Motivación}
Los efectos volumétricos como el fuego, el agua o el humo resultan indispensables para la creación de escenas 3D dotadas de fotorrealismo. No obstante, su implementación conlleva un elevado consumo de recursos computacionales debido al procesamiento masivo de datos que requieren.
Tradicionalmente, las APIs gráficas heredadas incurren en una notable saturación de la CPU derivada de las tareas de validación y control (\textit{CPU overhead}), lo cual merma significativamente el rendimiento global del sistema.

El objetivo principal de este proyecto reside en el renderizado eficiente de nubes masivas de partículas mediante la API de nueva generación Vulkan. 
Dicha interfaz facilita una comunicación directa y de bajo nivel con el hardware, eliminando abstracciones intermedias y posibilitando densidades de elementos computados órdenes de magnitud superiores. 
Para la consecución de tal fin, es preciso aplicar modelos matemáticos y leyes físicas sobre primitivas geométricas simples, persiguiendo en última instancia un equilibrio óptimo entre precisión perceptual y rendimiento de ejecución.

 
\section{Objetivos}
La finalidad del trabajo consiste en desarrollar un motor de partículas de alto rendimiento empleando la API Vulkan. Para lograrlo, se establecen los siguientes objetivos específicos:                                     

\begin{itemize}
    \item \textbf{Cómputo en GPU:} Delegar el procesamiento intensivo en la tarjeta gráfica. Se implementan \textit{Compute Shaders} encargados de computar el ciclo de vida, la matriz de transformación y las propiedades cromáticas de cada entidad, liberando a la CPU de dichas tareas.

    \item \textbf{Fluidos y gases:} Desarrollar algoritmos procedimentales ejecutables directamente sobre el hardware gráfico, con el fin de emular de forma perceptualmente rigurosa la dinámica física de líquidos y gases.                               

    \item \textbf{Efectos con volumen:} Generar volumen y densidad aparente en simulaciones como el fuego mediante la combinación iterativa de técnicas de mezcla aditiva (\textit{Alpha Blending}) aplicadas sobre primitivas puntuales (\textit{Point Sprites}).

    \item \textbf{Sincronización:} Implementar barreras de memoria explícitas y gestionar las dependencias en las colas de ejecución de Vulkan. Esto previene condiciones de carrera (\textit{race conditions}) durante el procesamiento paralelo masivo, garantizando la consistencia y el orden estricto entre operaciones asíncronas de lectura y escritura.

    \item \textbf{Control estético:} Diseñar modelos de materiales dinámicos cuyas propiedades fotométricas —luminancia, matiz y opacidad— evolucionen autónomamente en función de la madurez temporal (\textit{TTL}) de la partícula en simulación.
\end{itemize}
